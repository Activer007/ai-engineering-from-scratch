# 从 CLIP 到 BLIP-2：作为模态桥梁的 Q-Former

> CLIP 能对齐图像和文本，却无法生成图像描述、回答问题或进行对话。BLIP-2（Salesforce，2023）通过一个小型可训练桥接模块解决了这个问题：32 个可学习查询向量通过交叉注意力访问冻结的 ViT 特征，随后直接接入冻结的大语言模型（LLM）的输入流。这个拥有 188M 参数的桥接模块将一个 11B 的 LLM 与 ViT-g/14 连接起来。截至 2026 年，所有基于适配器的视觉语言模型（VLM），包括 MiniGPT-4、InstructBLIP 以及与 LLaVA 类似的模型，都是这一思路的后继者。本课将剖析桥接模块 Q-Former 的架构，解释其两阶段训练过程，并构建一个将视觉 token（词元）输入冻结文本解码器的简化版本。

**Type:** Build
**Languages:** Python (stdlib, cross-attention + learnable-query demo)
**Prerequisites:** 阶段 12 · 02（CLIP），阶段 7（Transformer）
**Time:** ~180 分钟

## 学习目标

- 解释为什么在冻结的视觉编码器与冻结的 LLM 之间设置可训练的瓶颈模块，在成本和稳定性上优于端到端微调（fine-tuning）。
- 实现一个交叉注意力块，让一组固定数量的可学习查询关注外部图像特征。
- 逐步梳理 BLIP-2 的两阶段预训练：先进行表示学习（ITC + ITM + ITG），再进行生成学习（使用冻结解码器的 LM 损失）。
- 将 Q-Former 与 LLaVA 使用的更简单的 MLP 投影器进行比较，并论证各自适用的场景。

## 要解决的问题

你有一个冻结的 ViT，它为每张图像生成 256 个维度为 1408 的图像块 token。你还有一个冻结的 7B LLM，它接收维度为 4096 的 token 嵌入（embedding）。最直接的桥接方法是使用一个从 1408 维映射到 4096 维的线性层。这种方法可行，但将全部 256 个图像块 token 输入 LLM 的上下文，会让每张图像额外占用 256 个 token。对于一个含 32 张图像的批次，仅视觉模态就会消耗 8192 个 token。

BLIP-2 要回答的问题是：能否将包含 256 个 token 的图像表示压缩为少得多的 token（例如 32 个），同时保留足够的信息，让 LLM 为图像生成描述、回答问题并进行推理？能否在不改动冻结主干网络的前提下训练这个桥接模块，让训练成本仅限于桥接模块自身的参数？

答案是 Q-Former。32 个可学习的“查询”向量通过交叉注意力访问 ViT 的图像块 token，生成供 LLM 使用的、包含 32 个 token 的视觉摘要。总计 188M 个参数。在接入 LLM 之前，就已经使用对比、匹配和生成目标完成训练。

## 核心概念

### 可学习查询

Q-Former 的核心技巧是：不让 LLM 的文本 token 直接关注图像块，而是引入一组新的、包含 32 个可学习查询向量的 `Q`，让*它们*来关注图像块。查询是模型的参数，会在训练过程中学习；每张图像都使用同一组 32 个查询。

经过交叉注意力后，每个查询都保存了一份压缩的图像摘要，例如“描述主要物体”“描述背景”“统计物体数量”等。查询并不会真的专门对应某个语义标签，而是学习任何能降低下游损失的编码方式。

### 架构

Q-Former 是一个小型 Transformer（12 层，~100M 个参数），包含两条路径：

1. 查询路径：32 个查询向量先经过彼此之间的自注意力，再通过交叉注意力访问冻结 ViT 的图像块 token，最后经过前馈网络（FFN）。
2. 文本路径：一个类似 BERT 的文本编码器，与查询路径共享自注意力和 FFN 的权重。文本路径不启用交叉注意力。

训练时，两条路径都会运行。查询和文本通过共享的自注意力交互，这意味着在需要的任务中（ITM、ITG），查询可以以文本为条件。推理时，在向 VLM 传递信息的环节中，只有查询通过该模块，产生 32 个视觉 token。

### 两阶段训练

BLIP-2 分两个阶段进行预训练：

阶段 1：表示学习（不使用 LLM）。包含三种损失：
- ITC（图文对比）：在池化后的查询 token 与文本 CLS token 之间进行 CLIP 式对比。
- ITM（图文匹配）：二分类器，判断这个图文对是否匹配。采用困难负样本挖掘。
- ITG（基于图像的文本生成）：以查询为条件，在文本侧使用因果语言模型（LM）输出头。迫使查询编码能够用于生成文本的内容。

只有 Q-Former 参与训练。ViT 保持冻结，不涉及 LLM。

阶段 2：生成学习。接入一个冻结的 LLM（OPT-2.7B 或 Flan-T5-XL 等）。通过一个小型线性层，将 32 个查询输出投影到 LLM 的嵌入维度。将它们放在文本提示词（prompt）前面。对拼接后的提示词 + 图像 + 图像描述序列计算 LM 损失，仅训练线性投影层和 Q-Former。

阶段 2 结束后，Q-Former + 投影层就构成了完整的视觉适配器。推理流程为：图像 → ViT → Q-Former → 线性投影 → 前置于文本 → 冻结的 LLM 生成输出。

### 参数成本

采用 ViT-g/14（1.1B，冻结）+ OPT-6.7B（6.7B，冻结）+ Q-Former（188M，训练）的 BLIP-2，总计 = 8B 个参数，其中训练 188M 个。单独的 Q-Former 约占整个系统参数量的 ~2.4%。训练成本也体现了这一点：只需少量 A100 训练几天，而端到端训练则需要数周。

质量方面：BLIP-2 在零样本视觉问答（VQA）上达到或超过 Flamingo-80B 的表现，而规模小了 50x。这个桥接模块确实有效。

### InstructBLIP 与可感知指令的 Q-Former

InstructBLIP（2023）为 Q-Former 增加了一个输入：指令文本本身。在计算交叉注意力时，查询现在可以同时访问图像块和指令。查询可以针对每条指令调整关注内容（“数一数汽车”“描述氛围”），而不是只学习一种固定的摘要方式。它在留出任务上的基准测试中获得了提升。

### MiniGPT-4 与仅训练投影器的方法

MiniGPT-4 保留了 Q-Former，但冻结其他所有部分，只训练输出线性投影层。这种方法成本低，但代价是质量：这些查询来自 BLIP-2，并非为你自己的任务学到的。它适合快速迭代，却不是最佳架构。

### LLaVA 为什么选择更简单的方法

LLaVA（2023，第 12.05 课）用一个普通的 2 层多层感知机（MLP）取代了 Q-Former，将 ViT 的每个图像块 token 投影到 LLM 空间。对于 24x24 的网格，每张图像会产生 576 个 token，全部输入 LLM。压缩程度更低，但允许 LLM 直接关注原始图像块。当时这一选择颇有争议；到 2023 年末，它已占据主导地位，因为视觉指令数据（LLaVA-Instruct-150k）证明，MLP 经过训练能够保留足够的信号。取舍在于：LLaVA 的上下文会更快被填满，但它能自然地扩展到多图像和视频场景。

到 2026 年，这一领域分成了两条路线：在 token 预算很重要的场景中（长视频、大量图像），Q-Former 依然有用；在优先考虑每个 token 所带来的原始质量时，MLP 投影器占据主导地位。

### 门控交叉注意力：先行者 Flamingo

Flamingo（第 12.04 课）早于 BLIP-2，使用了相同的交叉注意力思路，但将其用于冻结 LLM 的每一层，而非单个桥接模块。BLIP-2 表明，仅在输入层进行压缩也能奏效。Gemini 和 Idefics 将两者结合：交错排列的输入 token，加上可选的门控交叉注意力，用于上下文内少样本学习。

### 2026 年的后继方案

- Q-Former：BLIP-2、InstructBLIP、MiniGPT-4，以及出于 token 预算考虑采用这一方案的大多数视频语言模型。
- Perceiver 重采样器：Flamingo 的变体（第 12.04 课）；Idefics 系列、Eagle、OmniMAE。
- MLP 投影器：LLaVA、LLaVA-NeXT、LLaVA-OneVision、Cambrian-1。
- 注意力池化：VILA、PaliGemma。

这四种方案都可行。决定性问题在于：你受到的是 token 预算限制，还是每个 token 所能提供的质量限制。

## 实际使用

`code/main.py` 使用标准库构建一个 Q-Former 风格的交叉注意力模块：

1. 模拟 256 个图像块 token（维度 128）。
2. 实例化 32 个可学习查询（维度 128）。
3. 运行缩放点积交叉注意力（Q 来自查询，K/V 来自图像块）。
4. 通过线性层投影到 LLM 的维度（512）。
5. 输出 32 个可直接交给 LLM 的视觉 token。

所有数学运算都用纯 Python 实现（对向量使用嵌套循环）。虽然是简化示例，但形状正确。程序会打印注意力权重矩阵，便于你查看每个查询从哪些图像块提取了信息。

## 练习

1. 用 PyTorch 实现交叉注意力块。验证：在 32 个查询和 256 个键/值的情况下，注意力权重矩阵为 32 x 256，且经过 softmax 后每行之和为 1。

2. 在 BLIP-2 的阶段 1 中，Q-Former 同时计算三种损失：ITC、ITM、ITG。用伪代码写出每一种损失对应的前向计算签名。哪一种要求启用文本编码器路径？

3. 比较参数量：Q-Former（12 层，隐藏维度 768）与 2 层 MLP 投影器（1408 → 4096，两层）。LLM 达到多大规模时，188M 参数的 Q-Former 才能通过训练效率的提升抵消自身成本？

4. 阅读 BLIP-2 论文（arXiv:2301.12597）第 3.2 节，了解 Q-Former 的初始化方式。解释为什么使用 BERT-base 初始化（而非随机初始化）能加快收敛。

## 关键术语

| 术语 | 常见说法 | 实际含义 |
|------|----------------|------------------------|
| Q-Former | “查询式 Transformer” | 小型 Transformer，包含 32 个可学习查询向量，通过交叉注意力访问冻结的 ViT 特征 |
| 可学习查询 | “视觉的软提示词” | 充当交叉注意力查询端的一组数量固定的参数；在每个模型中学习，在所有输入之间共享 |
| 交叉注意力 | “Q 来自这里，K/V 来自那里” | 查询、键和值来自不同来源的注意力；查询通过这种机制从 ViT 图像块中提取信息 |
| ITC | “图文对比” | 对 Q-Former 池化后的查询与文本 CLS 应用的 CLIP 式损失 |
| ITM | “图文匹配” | 在经过困难负样本挖掘的样本对上运行的二分类器；迫使查询区分细粒度的不匹配 |
| ITG | “基于图像的文本生成” | 以查询为条件生成文本的因果 LM 损失；迫使查询编码可解码为文本的内容 |
| 两阶段预训练 | “先表示学习，再生成学习” | 阶段 1 仅训练 Q-Former（ITC/ITM/ITG）；阶段 2 接入冻结的 LLM，仅训练投影层 + Q-Former |
| 冻结的主干网络 | “不做微调” | 视觉编码器和 LLM 的权重固定不变；只有桥接模块参与训练 |
| 投影头 | “线性映射到 LLM 维度” | 将 Q-Former 输出映射到 LLM 嵌入维度的最后一个线性层 |
| Perceiver 重采样器 | “Flamingo 的版本” | 类似的可学习查询交叉注意力机制，Flamingo 将其用于每一层，而不是作为单个桥接模块 |
