## 独立审校单列的 14 组源风险

1. 模型、语料规模、精确配比和经验性比例断言未获本阶段外部事实重验
2. Chinchilla 条件、“相同损失”断言及 GPT-3 训练不足倍数缺少明确比较条件
3. 语言/质量/PII 筛查阈值与作用范围不能视为普遍保证；对应完整模块未在代码实现
4. 正则清洗保留 script 内文、合并相邻标签中的词，并删除非 ASCII 字符和制表符
5. 质量过滤只是启发式；`min_words=0` 的空输入会除零
6. 默认五词片段使短文片段集合为空，完全相同的短文仍可保留；阈值措辞与 `>=` 有区别
7. LSH 概率、分带参数与最坏复杂度存在限制，非整除尾部会被丢弃
8. 贪心重复删除不是连通分量去重，代表保留和遍历顺序存在边界
9. 实际只生成 padding mask，未实现正文承诺的跨文档分块对角掩码；图中 EOS 预算未计入
10. 全量 token/序列/索引列表不是端到端流式处理；没有 TB/GPU 吞吐保证或完整输入校验
11. 统计硬编码 token 0 为 padding，空输入/零词表可除零；字符/token 指标不等同存储压缩率
12. Project Gutenberg 与 WikiText 示例并非同一语料；外部对比和 10-50 倍性能未实测
13. 困惑度正文去除高值而练习称 bottom 20%，排序方向有歧义
14. 图、产出提示词、论文和网站适配各有验收边界；保留载荷不代表执行提示词或交互图通过

所有这些源风险均保留忠实译文，未修改英文或源码。
