## 源数学问题仍开放

每课review.json分别记录，英语源文及中文忠实保留；需另行决定技术纠错：

- 满秩 `rank=min(m,n)` 不保证宽矩阵最小二乘权重唯一，也不保证良态。反例：2×3满行秩矩阵允许两个不同权重得到同一输出；`diag(1,1e-12)`满秩但条件数为1e12
- 三个线性相关向量不一定张成平面，例如三个非零共线向量只张成直线
- 原点积方向类比、注意力等同正交投影、最小二乘系数等同投影、QR/Gram-Schmidt稳定性及LoRA子空间说法缺少条件或不准确
- 01/01正文Matrix没有练习要求的rank方法；01/02正文Matrix未展示@实现，但独立完整 `matrices.py` 确实定义了 `__matmul__`，不能扩大为整个实现缺失
- 广播兼容条件、空/零/不匹配输入、数值奇异阈值、每个全连接层都用ReLU以及BLAS 100x等说明各有适用条件；没有伪造性能实测

源S1问题不算翻译缺陷，但仍是发布技术门槛，demo成功不能关闭它们。
