## 独立审员记录的 17 组源风险

1. 正文只有前向计算，canonical 的反向传播与参数更新不完整
2. ReLU、缺失注意力偏置/dropout 和默认 float64 与完整 GPT-2 不同
3. 参数表各分项与总数不一致；实现的符号统计为 124,402,944
4. KV cache 描述遗漏新 token 自身 K/V 的计算和追加
5. 复杂度结论依赖固定维度、上下文长度和全量重算条件
6. GPT-2 内存算术成立，Llama 层数与 KV 头共享配置未验证
7. GPU 用时、算力/带宽瓶颈和单卡训练时长不能泛化
8. 残差与注意力头的作用不是保证，GPT-4 层数仍是传言
9. 历史训练默认值、初始化来源和论文归属未外部复核
10. 单头 attention 帮助函数的四维输入分支报轴数错误
11. 有限 `-1e9` 掩码、头维度、token 索引和序列长度存在边界
12. LayerNorm 与稳定 softmax 的数值结论需要条件
13. 数据截断、窗口采样、无验证集和损失曲线证据有限
14. 温度零会产生无效概率，未实现贪心或 top-k/top-p 分支
15. 上下文裁剪、位置重置、字节 ID 和 UTF-8 解码有范围限制
16. 练习与元数据不等于已实现功能，Rust 未读跑
17. 格式与网站验收分开；本轮 GFM 粗体已修复，原站中文锚点问题仍存在
