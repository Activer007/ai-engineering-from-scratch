## 仍开放的12项源风险

review.json逐项给出源行号、处置及证据，译文未暗改：

- 有限差分不适用于任意函数，固定极小h会受浮点消去、尺度和定义域影响；自动微分的“精确”不是无限精度保证
- 练习1按默认h=1e-7嵌套两次差分求x^3在2处的二阶导，实际约11.923795，而解析值12；需要步长/容差讨论，不能把练习视为精确相等测试
- Adam的梯度二阶原点矩不是中心化方差，也不是一般Hessian。[Adam原论文](https://arxiv.org/pdf/1412.6980)说明了一阶与二阶矩估计
- Newton、L-BFGS、自然梯度等表格的复杂度/收敛速度缺少条件；负Hessian时Newton步可增加函数值
- 无约束一阶Taylor线性模型通常没有有限极小值，不能直接推出有限梯度下降步；光滑也不保证等于无限Taylor级数
- 在0处sin的二阶项为0，本课一阶/二阶结果相同，“项更多就更好”不能无条件成立
- 局部与全局极小值、欧氏最速方向、泛化的训练循环/平滑损失、多路径反传前提、softmax有限求和与连续积分等教学边界单列

正常示例exit0不能关闭这些源数学/数值问题，源技术修正仍需另行决定。
