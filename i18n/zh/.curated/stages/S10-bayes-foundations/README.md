## 源统计与代码风险

review.json单列12组源问题，未静默修正文或代码：

- 文档出现频率与词项计数的朴素Bayes模型切换；给定类别的条件独立不能改成无条件独立
- 任意偏好小参数的先验并不都等于L2；MAP的先验/负log尺度和参数化要明确，MAP不是后验均值
- 频率学派不只输出点估计，SGD不专属于一种统计框架，Bayesian方法也不自动保证校准或避免过拟合
- 共轭依赖似然与参数化，Gamma更新式采用rate；非共轭不必只能MCMC/变分推断，共轭也不普遍只需更新两个数
- 未知词仍被计入评分但不进入词表归一化；空模型/零证据/零平滑有边界；手写分词与CountVectorizer并不完全相同
- “均匀先验等于毫无倾向”、Beta参数和浓度、顺序更新数据假设及医学两次检测的条件独立都需要语境限定

### 可选停止：必须区分三个口径

后验是否依赖停止规则、后验校准、频率学派错误率控制是不同性质，不能由普通 `P(B>A)>0.95` 自动推出“随时查看不增加误报率”。相关原论文分别讨论了这些条件：[Hendriksen等](https://arxiv.org/abs/1807.09077)、[de Heide与Grünwald](https://arxiv.org/abs/1708.08278)。正规的频率学派序贯方法也不能被概括成“一提前看就必然失效”。

为核查源普遍化说法，两套独立标准库有理数计算使用同一明确反例：两个独立Bernoulli臂、固定真实率均为0.5、各Beta(1,1)先验、每次每臂新增1个观测、最多各20个。固定终点和每步查看使用相同严格后验边界。

- 单向只在P(B>A)>0.95时报B优势：固定终点频率错误率约4.0635%，任何一步越界则约15.8095%
- 双向首次越P(B>A)>0.95或<0.05即选择变体：固定终点任一方向约8.1271%，顺序首次越界约31.5881%

完整分数、参数和方法写入review。这是该固定null与规则下的反例，不是声称所有Bayesian可选停止都无效，不是原50/1000与65/1000样例的错误率，也不否定后验自洽。译文保留源断言，技术修正仍需另行决定。
