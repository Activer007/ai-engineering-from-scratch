正式术语基线：actual103，83份TERM（81 accepted stage＋core2），各路径和固定来源见同目录 DEPENDENCIES.json。旧 pending S61/S66/S79 未纳入。作者完整英文阅读后提出以下词义；没有复用旧中文课文、segments或format_revisions。

| Source term | Chinese treatment | Fidelity boundary |
|---|---|---|
| assumption | 假设 | A condition or falsifiable claim; do not confuse it with an implementation task |
| assumption map | 假设图（assumption map） | Exact S84 term; never alter the `assumption-map.json` path |
| workflow | 工作流（workflow） | Exact S84 term; preserve approval workflow as a workflow, rather than a single permission event |
| evidence | 证据 | Exact S84 term; presence in a string does not mean validated, credible, sufficient, or supporting evidence |
| outcome | 结果；预期结果 | Exact S84 term; in the value-class question, this is the effect that matters to users, not a file generated by code |
| output | 产出；code I/O may use 输出 | S84 contextual term; keep separate from outcome and artifact; the literal `outputs/` path stays unchanged |
| impact | 影响程度 | Defined as damage if an assumption is false; do not turn this into generic feature benefit |
| uncertainty | 不确定性 | Defined by weakness of current evidence |
| irreversibility | 不可逆性 | Defined here by the cost of learning after commitment |
| reversibility | 可逆性 | Maintain its relationship to ordering safe tests before costly commitments |
| risk score / risk ranking | 风险评分 / 风险排序 | The sample score is illustrative, not a universal metric |
| open risk / open claim | 尚未验证的风险 / 尚未验证的主张 | Avoid making `open` mean “open source” or “unresolved incident”; preserve code status strings verbatim |
| tested assumption | 经过检验的假设 | Narrative wording needs care: the executable status is only determined by evidence truthiness |
| falsifiable statement | 可证伪的陈述 | Must allow an observable failure, rather than merely a demonstration |
| decisive experiment / test | 足以作出决策的实验 / 检验 | Keep the decision-changing sense without implying successful confirmation |
| ambiguous evidence | 尚不足以明确判断的证据 | Preserve the third decision branch beyond pass/fail |
| commitment | 作出投入或承诺, context-dependent | In irreversible choices this encompasses costly commitment, not only a spoken promise |
| value | 价值 | Keep separate from feasibility and viability |
| usability | 可用性 | Question is whether a user can understand and act; do not substitute availability |
| feasibility | 可行性 | Available data and constraints |
| viability | 可持续性（viability） | Organization's ability to sustain cost, ownership, and operations; local context choice distinct from feasibility |
| safety | 安全性 | Unacceptable consequences of failure |
| read-only replay | 只读回放 | Keep read-only and historical replay distinctions |
| production integration | 生产环境集成 | Must not imply the demo actually performs production operations |
| authority | 权限（authority）；归属语境用权限归属 | Consistent with S84 meaning of permitted access/actions; this source says unsafe authority, not who owns authority; do not invent a required role |
| human-approved recommendation | 经人工批准的建议 | Preserve approval prerequisite and recommendation scope |
| roadmap | 路线图 | Roadmap priority can differ from experiment risk ranking |
| incident tool / on-call engineer | 事件处理工具 / 值班工程师 | Incident wording follows S84's 事件 family; operational incident, not a news/event sense |
| incident commander | 事件指挥员 | Exact S84 term; sample string remains protected English |
| automatic remediation | 自动修复 | Occurs only in stored sample statements; no actual remediation is authorized |

Proper names and titles in reference link labels, literal identifiers, status values (`open`, `tested`), commands, code, paths, diagram labels, and numeric sample values should remain protected per the fixed support rules. Proposal entries do not authorize translating protected spans.
