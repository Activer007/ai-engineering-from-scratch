# S81 结果与产出术语

固定来源：14-47 英语1bafaa88bb4668356791150bec3a6d7df38387eb。沿用核心表/addendum及83个已验支持文件；不使用历史中文课文。

| EN | ZH | 语境与限制 |
|---|---|---|
| outcome | 结果；预期结果 | 可观察的改善，不等同于交付文件或功能 |
| output | 产出 | 具体软件、文档或界面等交付形态，区别模型输出 |
| outcome frame | 结果框架（outcome frame） | 用户、情境、当前行为、预期结果、约束、非目标六要素；不是软件运行框架 |
| solution leakage | 预设方案混入（solution leakage） | 尚无证据支撑的方案先被写入结果描述；不是数据泄露或信息安全漏洞 |
| constraint / non-goal | 约束 / 非目标 | 固定限制及明确不做的相邻工作，两者不混 |
| incident assistant | 事件处理助手 | 教学中的产出名称，不是真实产品或生产操作 |
| on-call engineer | 值班工程师 | 教学例子中的直接用户 |
| incident commander | 事件指挥员 | 事件响应协调角色，不等同于智能体 |
| runbook | 操作手册（runbook） | 可用于实现同一结果的操作说明 |
| auditable / audit trail | 可审计 / 审计轨迹 | 过程可追溯，不声称真实生产审计已通过 |
| slice | 本次工作范围 | 将工作限制在小范围，不作数据切片解释 |
| artifact | 产物 | 沿核心表，具体可交付对象 |
| observable / falsify | 可观察 / 证伪 | 可检查结果状态及最早反例，不由简单校验器保证 |
