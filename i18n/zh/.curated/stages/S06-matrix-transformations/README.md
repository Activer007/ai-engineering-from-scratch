## 源问题与发布技术门槛

review.json记录10类源问题及行号，译文保留源义，没有静默纠正：

- 行列式符号与绝对值混淆：反射det=-1，但绝对值为1；源保护围栏把绝对值写成-1
- 特征分解一般是换基，不一定正交旋转；源示例 `[[3,1],[0,2]]` 的两个单位特征向量点积约0.7071
- 源复特征向量按分量平方和归一化，对90°旋转矩阵和特征值i，非零向量[-1,i]得到零分母；已实际复现ZeroDivisionError
- 双参数shear返回 `[[1,kx],[ky,1]]`，当kx=ky=1时det=0，不是一般保面积剪切
- 特征向量“从不旋转”未细分负/零/复特征值；RNN谱稳定性、神经网络均为线性操作、特征值决定PCA方向等教学概括过宽
- 奇异变换的标准基像不一定形成新基；手写2x2闭式代码也不等同生产通用特征求解器。[NumPy官方eig说明](https://numpy.org/doc/stable/reference/generated/numpy.linalg.eig.html)明确其使用LAPACK geev，且一般特征向量矩阵不保证酉

前四类已有独立数值/源程序反例；正常demo与例子exit0不能关闭这些问题。源技术纠错仍需另行决定。
