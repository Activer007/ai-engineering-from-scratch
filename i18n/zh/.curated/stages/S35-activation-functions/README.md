## 独立记录的 14 组源问题

1. 仿射与线性混用、列向量下矩阵复合次序，以及表达能力需要的条件
2. 激活函数历史、流行程度与普适选择建议未在本次验证
3. 局部激活导数不等于完整网络梯度，权重、Jacobian、掩码与其他路径不能省略
4. 以零为中心的值域不保证每批均值为零，也不保证所有梯度同号或消除之字形优化
5. ReLU 与 Leaky ReLU 零点不可微的约定、有限样本失活与永久失活的区别，以及负侧正斜率
6. GELU 概率解释及前向近似与导数错配：前向用 tanh 近似，导数对应精确 `x*Phi(x)`；独立有限差分最大抽样误差约 0.00086746
7. 浮点端点、sigmoid 截断分支与导数不一致，以及空值和非有限输入边界
8. softmax 为向量函数、缺少 Jacobian 实现及其内部用途、校准与 logits 损失的边界
9. 梯度扫描只覆盖 [-5, 4.9]，近零阈值与实际训练中的失活率不同
10. 前向实验仅测激活值幅度，不测反向梯度；因此不能用该输出证明某激活函数的梯度性质
11. 20 个神经元对 1000 个有限随机输入的零激活计数不构成训练中或全部输入上的永久失活证明
12. 训练更新对应半平方误差，而报告 loss 为完整平方误差，差一个常数 2；在线训练准确率也不是冻结最终模型的验证集指标
13. 有限标准库演示的运行边界；Torch 跳过，独立审员未验证 canonical 或生产鲁棒性
14. 原图、练习启发式及参考保留；练习未全部完成，实际 GitHub 渲染不覆盖课程站点交互
