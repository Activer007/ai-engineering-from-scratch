## 独立记录的 16 组源风险

1. MSE 分类必然预测常数 0.5 的断言不成立；两损失在平衡常数模型内都以 0.5 为最优
2. 本课带负样本 InfoNCE 的表示坍缩损失为 `log(8)` 等值，不是零
3. BCE 对概率与 logit 的导数混同；交叉熵与 KL 相差目标熵，也不是对概率的指数惩罚
4. 标签平滑的 0.91 与 0.9 数值冲突，以及 softmax 的 logit 差条件
5. GPT 与大多数现代模型普遍使用标签平滑的泛化未被本次确认
6. InfoNCE 文字称分母仅负样本，而实现包含正样本
7. 双视图 SimCLR 负样本计数与教材的 255 不同；默认温度声明需限定来源
8. 低温度不保证损失更高，也不使负样本本身变难
9. 单项三元组损失为零不代表优化器完全不更新；半困难负样本缺少间隔上界
10. 焦点损失在 gamma=0 时仍保留 alpha；权重因子不是完整梯度
11. 预测变量上的 MSE 曲面不能推广为深网参数空间单极小点，损失也未必处处可微
12. 正文 BCE 梯度缺均值因子，canonical 已包含 `1/n`
13. 裁剪与舍入后的导数边界，以及未实现 InfoNCE 梯度的范围
14. softmax 后取 log 的数值稳定性解释和 `nll_loss` 输入类型边界
15. Huber、平滑 L1 与 MSE 的阈值和缩放区别
16. 英文元数据只列 Python，但固定目录存在 `main.jl`；译文元数据保持源样
