## 独立审校单列的 15 组源问题

1. 原 2013 论文的有限摘录不支持课文并列的“万亿 token”历史规模；译文保持源量级，独立核查的论文摘录不等于完整论文复现
2. TF-IDF 泛化限制、默认 Skip-gram、生产使用/下载习惯、笔记本训练时间和 2026 优势均缺任务与版本边界
3. 全词表 softmax 与负采样二分类目标不同；均匀负词不等同论文噪声分布，也不保证全局不共现
4. 两表梯度在未截断区间的有限差分通过；自赋值无效，sigmoid 超界截断改变目标导数关系
5. 正文抽 k、canonical 抽 2k 再筛除，均可能不足 k 或没有负词；重复索引保留且正确累加
6. 正文默认 100 轮、canonical 函数默认 200 轮、main 实际 120 轮；正文依赖另处定义的 `build_vocab`
7. nearest 没有验证非正 topk、零向量与词表/形状一致性；epsilon 使自相似略低于一
8. 类比方向在合成几何中正确；预训练邻居/分数及向量等号不是普遍保证
9. 从每个向量减去一个性别均值向量，不保证去除投影或实现公平性
10. 可视化、多义性解决、fastText 词表外覆盖均有条件；原 ASCII 分词器仍限制语言覆盖
11. 输出提示词的 0.01/100 范数阈值不能普遍证明训练错误；仅保存内容，不执行提示词
12. 20 句与 200 轮不保证练习中的 dog 进入前三，扩大词表也不保证修复
13. 高频词按频率成正比丢弃不是论文完整非线性子采样规则；`10^-5` 原样保留
14. 源 Unicode 图、figure 标识、缺 canonical 引用头和 tests 的仓库规范问题保留；小语料输出不等于完整 CBOW/softmax/下游验证
15. 原站点 parser 的中文标题锚点问题须与实际 GitHub GFM、课程网站及移动/交互验收分开
