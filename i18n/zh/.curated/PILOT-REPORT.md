## 仍未关闭的门槛

### 1. 英文源本身的技术/实现问题

每课 `review.json` 记录了详细来源行与说明，以下仅列高风险类别：

- KV cache 的部分容量计算漏掉 heads 因子，复杂度/操作次数与演示代码不符，浮点“逐位相同”断言不严谨
- LoRA/QLoRA 显存数值、示例可训练比例及真实 NF4 行为混杂；GPT 的 LLaMA 改造和负 logit 重复惩罚描述有遗漏
- 安全护栏中存在“组合后 100% 防御”等过度保证；产品类别、版本、免费/限流声明需按日期核实
- BLIP-2 文字与演示维度不一致，视频采样算术有问题；任务 schema 文字与验证器允许值不完全一致
- 编辑器说明的 `.vscode` 路径与实际文件不符；Registry 连续实验的回滚前提冲突；工作台承诺部分未实现功能；负载模拟器并不测量文中所称的 TPOT

本批保留固定英文的含义，没有在翻译中悄悄“修正事实”。下一步应在本 fork 内单独审议英文源修复，再同步中文。不要把这些忠实草稿直接当作当前产品说明或生产安全保证。

### 2. 网站渲染与发布

实际网站浏览器预览受当前环境限制，仍为 **BLOCKED / UNPASSED**。离线运行原站解析器发现：纯中文标题会得到空锚点；英文专用章节样式也不识别中文。原站课程请求还硬编码历史 `translations` 来源。后续需在独立站点适配工作中：

1. 明确使用本 fork、`zh-curated` 与新审核清单
2. 支持中文标题锚点、多反引号快捷键和字面数学符号
3. 缺少中文时明确显示固定英文及未完成状态，绝不回退历史旧中文
4. 在可用环境逐课进行真实页面、导航、代码复制和移动端验收
5. 经授权决定是否启用只读 CI；合并、发布和部署仍须用户批准

GitHub 能显示 `figure` 围栏中的标识符，但不会运行原站的交互图。重放命令只生成 zh.md；它不是包含 SVG 与站点资源的完整发布包。

### 3. 未执行的运行面

LoRA 与 GPT 示例因缺少 torch 未运行；没有安装依赖。未执行可触发下载的 tiktoken/提供商集成、Julia、编辑器/SSH 安装器、真实模型 API 或真实负载测试。安全的本地演示结果逐课列在审核记录中；没有把部分测试说成全套通过。
